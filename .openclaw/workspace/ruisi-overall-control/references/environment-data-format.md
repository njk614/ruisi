# 环境数据模拟格式

## 查询接口

**路径**：`GET /api/environment/query?zone=<zone>`（模拟）

**模拟响应 JSON 结构**：

```json
{
  "temperature": 18,
  "humidity": 60,
  "illuminance": 150
}
```

## 字段说明

| 字段          | 类型   | 单位 | 范围    | 说明     |
| ------------- | ------ | ---- | ------- | -------- |
| `temperature` | number | °C   | -10~50  | 环境温度 |
| `humidity`    | number | %RH  | 0~100   | 相对湿度 |
| `illuminance` | number | lux  | 0~10000 | 光照度   |

## 舒适阈值与调节触发条件

| 指标 | 舒适范围  | 触发调节条件       | 调节动作            |
| ---- | --------- | ------------------ | ------------------- |
| 温度 | 22~26°C   | `< 22°C`           | 空调制热，目标 24°C |
| 温度 | 22~26°C   | `> 26°C`           | 空调制冷，目标 24°C |
| 湿度 | 40~60%    | （本期不调节湿度） | —                   |
| 光照 | ≥ 300 lux | `< 300 lux`        | 开灯，亮度 80%      |

## 区域模拟数据参考

| 区域                 | 典型温度 | 典型湿度 | 典型光照 | 说明                     |
| -------------------- | -------- | -------- | -------- | ------------------------ |
| `entrance`           | 25       | 55       | 500      | 门厅，光照充足           |
| `meeting-room-large` | 18       | 60       | 150      | 大会议室，空调未开时偏冷 |
| `main-hall`          | 28       | 45       | 800      | 主场，朝南光照好         |

## 错误响应

若环境数据不可用，模拟接口返回：

```json
{ "success": false, "message": "环境数据暂不可用" }
```
