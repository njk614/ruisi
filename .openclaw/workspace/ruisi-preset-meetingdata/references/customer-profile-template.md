# 客户画像模板

生成客户画像时严格保持以下结构，可替换示例内容。

```markdown
# 客户画像

## 基本信息

| 字段 | 内容 |
|------|------|
| **公司名称** | 客户公司完整名称 |
| **行业领域** | 行业领域 |
| **会议主题** | 当前会议主题 |
| **会议时间** | 当前会议时间 |
| **会议区域** | 会议室或区域 |
| **访客人数** | N 人 |
| **主要兴趣点（团队整体）** | 团队整体兴趣点 |

---

## 公司背景

填写客户公司背景、行业定位、主营业务、与会议主题相关的公开信息。

---

## 合作项目

- 合作项目一
- 合作项目二

---

## 来访人员列表

### 来访人员姓名

| 字段 | 内容 |
|------|------|
| **姓名** | 姓名 |
| **职位** | 职位 |
| **亲切称呼** | 例如何总、李工、王经理 |
| **角色分类** | 决策人 / 技术评估人 / 业务引入人等 |
| **主要关注点（个人）** | 个人关注点 |
| **历史来访次数** | 首次 / N 次 |
| **是否需要特殊接待** | 无 / 具体要求 |

---

## 补充备注

- 补充信息一
- 补充信息二

---

## 生成的讲解脚本关联

本画像对应的讲解脚本文件：`../PresentationScript.json`

---

**生成时间**：ISO8601 时间
**生成工具**：智能接待系统 - 预置会议数据生成器
```
