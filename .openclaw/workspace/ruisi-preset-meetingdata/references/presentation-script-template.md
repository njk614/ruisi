# 讲解脚本表格模板

`PresentationScript.md` 必须使用表格结构。

## 表头

```markdown
| 章节ID | 章节主题 | 段落ID | 文本内容 | 时长(s) | 资源类型 | 资源URL | 资源参数 | 资源描述 | 音频文件 | 表演素材码 | 表演描述 |
|--------|----------|--------|----------|---------|----------|---------|----------|----------|----------|------------|----------|
```

## 示例

```markdown
| 1 | 开场致辞 | 1 | 尊敬的各位领导、专家，大家好！我是数字冰雹AI助理。 |  | image | /images/welcome.png | - | 欢迎背景 | audio/audio_001_01.mp3 | bow | 动作-鞠躬 |
| 1 | 开场致辞 | 2 | 非常荣幸能在这里汇报我们的技术积累与产品体系。 |  | - | - | - | - | audio/audio_001_02.mp3 | smile | 表情-微笑 |
```

## 讲解主体身份

- 讲解主体固定为“数字冰雹AI助理”或“数字冰雹AI接待助理”。
- 口播中的第一人称“我”只代表 AI 助理，不代表 `booker_name` 或 `internal_attendees` 中的任何人类员工。
- `booker_name` 和 `internal_attendees` 只能作为会议预约人、我方参会人员、陪同人员或后续答疑支持人员使用，严禁作为第一人称讲解人、汇报人或联合汇报人。
- 不得出现“我是来自数字冰雹的某某”“我是数字冰雹的某某”“接下来由我和我的同事某某为大家汇报”“由某某和某某为大家汇报”等表达。
- 推荐开场口径：尊敬的各位领导、专家，大家好！我是数字冰雹AI助理，接下来由我为大家介绍数字冰雹在数字孪生领域的技术积累与产品体系。

## 核心规则

- 每个独立展示资源实例对应一个章节。
- 每个段落文本内容不超过 60 字。
- 第一段填写完整资源字段。
- 同一章节第二段及后续段落资源字段填 `-`。
- 初次生成时 `时长(s)` 必须填写模拟时长，不能留空。
- 模拟时长根据段落文本长度估算，范围限制在 8 到 25 秒。
- 推荐估算规则：去除空白后的文本长度除以 4 后向上取整，再加 2 秒，最终限制在 8 到 25 秒之间。
- 音频文件使用 `audio/audio_001_01.mp3` 格式。
- 资源URL 必须原样使用 `resource_catalog.json` 中对应资源的 `file_path` 字段；如果是完整网络地址，必须完整保留，不能改成相对路径。
- 开场和后续第一人称均代表数字冰雹AI助理，不得代入我方参会人员。

## 可用表演素材码

动作：`wave`、`nod`、`shake_head`、`point`、`spread_hands`、`thumbs_up`、`clap`、`bow`、`heart`、`ok`

表情：`neutral`、`smile`、`laugh`、`cover_mouth_laugh`、`awkward`、`surprise`、`puzzled`、`serious`、`blink`、`wink`
