# 讲解脚本表格模板

`PresentationScript.md` 必须使用表格结构。

## 表头

```markdown
| 章节ID | 章节主题 | 段落ID | 文本内容 | 时长(s) | 资源类型 | 资源URL | 资源参数 | 资源描述 | 音频文件 | 表演素材码 | 素材时长(s) | 推送间隔(s) | 表演描述 |
| ------ | -------- | ------ | -------- | ------- | -------- | ------- | -------- | -------- | -------- | ---------- | ----------- | ----------- | -------- |
```

## 示例

```markdown
| 1 | 开场致辞 | 1 | 尊敬的各位领导、专家，大家好！我是数字冰雹AI助理。 | - | image | /images/welcome.png | - | 欢迎背景 | http://172.16.1.138:8888/SimulatedData/PresetMeetingData/M20260610_001/audio/audio_001_01.mp3 | wave | 4 | - | 动作-挥手 |
| 1 | 开场致辞 | 2 | 非常荣幸能在这里汇报我们的技术积累与产品体系。 | - | - | - | - | - | http://172.16.1.138:8888/SimulatedData/PresetMeetingData/M20260610_001/audio/audio_001_02.mp3 | smile | 5 | - | 表情-微笑 |
```

## 讲解主体身份

- 讲解主体固定为“数字冰雹AI助理”或“数字冰雹AI接待助理”。
- 口播中的第一人称“我”只代表 AI 助理，不代表 `booker_name` 或 `internal_attendees` 中的任何人类员工。
- `booker_name` 和 `internal_attendees` 只能作为会议预约人、我方参会人员、陪同人员或后续答疑支持人员使用，严禁作为第一人称讲解人、汇报人或联合汇报人。
- 不得出现“我是来自数字冰雹的某某”“我是数字冰雹的某某”“接下来由我和我的同事某某为大家汇报”“由某某和某某为大家汇报”等表达。
- 推荐开场口径：尊敬的各位领导、专家，大家好！我是数字冰雹AI助理，接下来由我为大家介绍数字冰雹在数字孪生领域的技术积累与产品体系。

## 核心规则

- 每个独立展示资源实例对应一个章节。
- 每个段落文本内容不超过 60 字。
- 第一段填写完整资源字段。
- 同一章节第二段及后续段落资源字段填 `-`。
- 初次生成 `PresentationScript.md` 时，音频尚未生成，`时长(s)` 必须先填 `-`，不得填写模拟时长。
- 音频文件必须填写完整 HTTP 地址，格式为 `http://172.16.1.138:8888/SimulatedData/PresetMeetingData/<booking_id>/audio/audio_001_01.mp3`。
- `<booking_id>` 必须使用当前会议真实 `booking_id`，不得使用会议主题、会议室名称或其他文本。
- 完整 HTTP 音频地址只作为最终脚本对外使用的访问地址；TTS 生成和时长回填时必须只取音频文件名，实际写入和读取本地 `<meeting_dir>/audio/<音频文件名>`。
- 资源URL 必须原样使用 `resource_catalog.json` 中对应资源的 `file_path` 字段；如果是完整网络地址，必须完整保留，不能改成相对路径。
- 开场和后续第一人称均代表数字冰雹AI助理，不得代入我方参会人员。
- `表演素材码` 后必须填写 `素材时长(s)` 字段；使用表演素材时填写对应素材秒数，不使用表演素材时填 `-`。
- 当前仅启用动作素材 `wave`、`point`、`nod`、`shake_head`，素材时长均为 4 秒。
- 当前仅启用表情素材 `smile` 5 秒、`laugh` 3 秒、`cover_mouth_laugh` 4 秒。
- 暂未启用的其他动作或表情素材不得生成到讲解脚本中。
- `推送间隔(s)` 表示当前段落消息推送完成后，到下一条消息的等待间隔。
- 初次生成 `PresentationScript.md` 时，`推送间隔(s)` 必须先填 `-`。
- 真实音频生成后，读取音频文件实际时长并向上取整回填 `时长(s)`；例如 1.1 秒、1.9 秒都回填为 2 秒。
- 回填后，`推送间隔(s)` 必须等于 `时长(s)` 加 `素材时长(s)`；未使用表演素材时，`素材时长(s)` 按 0 计算，即 `推送间隔(s)` 等于 `时长(s)`。

## 可用表演素材码

动作：`wave`、`point`、`nod`、`shake_head`

表情：`smile`、`laugh`、`cover_mouth_laugh`
