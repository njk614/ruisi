# 设备控制接口约定

## 通用约定

| 项目             | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| 协议             | HTTP POST                                                |
| Content-Type     | `application/json`                                       |
| 超时             | 5 秒                                                     |
| 重试策略         | 失败后重试 1 次                                          |
| 响应格式（统一） | `{"success": bool, "message": string}`                   |
| 基础 URL         | `http://127.0.0.1:18900/api`（模拟，后续替换为真实地址） |

## 1. 孪易大屏控制接口

**路径**：`POST /api/twinscreen/control`

### 请求体通用结构

```json
{
  "zone": "meeting_room",
  "指令": "功能切换",
  "参数": {
    "功能名称": "分析"
  }
}
```

### 字段说明

| 字段   | 类型   | 必填       | 说明                                    |
| ------ | ------ | ---------- | --------------------------------------- |
| `zone` | string | 是         | 区域标识（meeting_room / main_hall 等） |
| `指令` | string | 是         | 中文指令名称，取值见下方                |
| `参数` | object | 取决于指令 | 指令的参数，取值见下方                  |

### 指令列表

#### 1.1 基础

| 指令     | 参数                   | 参数说明                   | 示例                      |
| -------- | ---------------------- | -------------------------- | ------------------------- |
| 功能切换 | `{"功能名称": "<值>"}` | 分析/对象/告警/过滤/AI分析 | `{"功能名称":"分析"}`     |
| 主题切换 | `{"主题名称": "<值>"}` | 智能匹配 ThemeNamesStr     | `{"主题名称":"深色主题"}` |

**请求示例**：

```json
{ "zone": "meeting_room", "指令": "功能切换", "参数": { "功能名称": "分析" } }
```

#### 1.2 场景

| 指令     | 参数                   | 参数说明                                    | 示例                  |
| -------- | ---------------------- | ------------------------------------------- | --------------------- |
| 层级切换 | `{"层级名称": "<值>"}` | 层/楼层/level/floor，智能匹配 LevelNamesStr | `{"层级名称":"20层"}` |
| 下一层   | `{}`                   | 无参数                                      | `{}`                  |
| 上一层   | `{}`                   | 无参数                                      | `{}`                  |
| 顶层     | `{}`                   | 最后一层、最高层                            | `{}`                  |
| 底层     | `{}`                   | 第一层、首层                                | `{}`                  |

#### 1.3 视野

| 指令     | 参数                             | 参数说明                                           | 示例                          |
| -------- | -------------------------------- | -------------------------------------------------- | ----------------------------- |
| 场景旋转 | `{"开始/停止": "<值>"}`          | 场景/摄像机视野旋转，开始/停止                     | `{"开始/停止":"开始"}`        |
| 场景复位 | `{}`                             | 场景复位、视野复位、默认视野                       | `{}`                          |
| 视野放缩 | `{"远近": "<值>", "距离": <数>}` | 拉近/远离、视野拉近/拉远，距离 0-100               | `{"远近":"拉近","距离":50}`   |
| 视野平移 | `{"方向": "<值>", "距离": <数>}` | 前移/后移/左移/右移，视野移动/视角移动，距离 0-100 | `{"方向":"前移","距离":30}`   |
| 视野旋转 | `{"方向": "<值>", "角度": <数>}` | 顺时针/逆时针、向左/向右，角度 -360~360            | `{"方向":"顺时针","角度":90}` |

#### 1.4 时间轴

| 指令     | 参数                                    | 参数说明                | 示例                               |
| -------- | --------------------------------------- | ----------------------- | ---------------------------------- |
| 模式切换 | `{"模式": "<值>"}`                      | 实时/回放               | `{"模式":"回放"}`                  |
| 播放     | `{}`                                    | 无参数                  | `{}`                               |
| 暂停     | `{}`                                    | 无参数                  | `{}`                               |
| 跳转     | `{"回退/前进": "<值>", "百分比": <数>}` | 回退/前进，百分比 0-100 | `{"回退/前进":"前进","百分比":50}` |

#### 1.5 图层

| 指令     | 参数                    | 参数说明         | 示例                      |
| -------- | ----------------------- | ---------------- | ------------------------- |
| 图层管理 | `{"打开/关闭": "<值>"}` | 面板开关         | `{"打开/关闭":"打开"}`    |
| 显示图层 | `{"图层名称": "<值>"}`  | 要显示的图层名称 | `{"图层名称":"建筑轮廓"}` |
| 隐藏图层 | `{"图层名称": "<值>"}`  | 要隐藏的图层名称 | `{"图层名称":"建筑轮廓"}` |
| 全部显示 | `{}`                    | 无参数           | `{}`                      |
| 全部隐藏 | `{}`                    | 无参数           | `{}`                      |

#### 1.6 图表

| 指令     | 参数                    | 参数说明 | 示例                      |
| -------- | ----------------------- | -------- | ------------------------- |
| 图表管理 | `{"打开/关闭": "<值>"}` | 面板开关 | `{"打开/关闭":"打开"}`    |
| 显示图表 | `{"图表名称": "<值>"}`  | 图表名称 | `{"图表名称":"能耗趋势"}` |
| 关闭图表 | `{"图表名称": "<值>"}`  | 图表名称 | `{"图表名称":"能耗趋势"}` |

#### 1.7 环境控制

| 指令     | 参数                    | 参数说明                                                  | 示例                   |
| -------- | ----------------------- | --------------------------------------------------------- | ---------------------- |
| 环境控制 | `{"打开/关闭": "<值>"}` | 面板开关                                                  | `{"打开/关闭":"打开"}` |
| 时间切换 | `{"时间": "<值>"}`      | 上午/下午/傍晚                                            | `{"时间":"下午"}`      |
| 季节切换 | `{"季节": "<值>"}`      | 春季/夏季/秋季/冬季                                       | `{"季节":"夏季"}`      |
| 天气切换 | `{"天气": "<值>"}`      | 晴/晴间多云/阴天/小雨/中雨/大雨/小雪/中雪/大雪/雾/扬沙/霾 | `{"天气":"晴"}`        |

#### 1.8 对象列表

| 指令     | 参数                   | 参数说明         | 示例                         |
| -------- | ---------------------- | ---------------- | ---------------------------- |
| 聚焦对象 | `{"对象名称": "<值>"}` | 聚焦到指定对象   | `{"对象名称":"3号发电机组"}` |
| 选中对象 | `{"对象名称": "<值>"}` | 选中指定对象     | `{"对象名称":"3号发电机组"}` |
| 取消选中 | `{"对象名称": "<值>"}` | 取消选中指定对象 | `{"对象名称":"3号发电机组"}` |
| 对象下钻 | `{"对象名称": "<值>"}` | 下钻到指定对象   | `{"对象名称":"3号发电机组"}` |
| 对象上卷 | `{}`                   | 上卷返回上一层   | `{}`                         |
| 搜索对象 | `{"对象名称": "<值>"}` | 查找指定对象     | `{"对象名称":"发电机组"}`    |

## 2. 照明控制接口

**路径**：`POST /api/lighting/control`

### 请求体通用结构

```json
{
  "zone": "meeting_room",
  "设备": [{ "设备名称": "light_001", "指令": "调节亮度", "参数": { "亮度百分比": 80 } }],
  "全部": false
}
```

### 字段说明

| 字段   | 类型    | 必填                | 说明                                              |
| ------ | ------- | ------------------- | ------------------------------------------------- |
| `zone` | string  | 是                  | 区域标识（entrance / meeting_room / main_hall）   |
| `设备` | array   | 当全部=false 时必填 | 设备操作列表，每项含 设备名称/指令/参数           |
| `全部` | boolean | 否                  | 若为 true，控制该区域所有照明设备（忽略设备列表） |

### 指令列表

| 指令     | 参数                   | 参数说明               | 示例                |
| -------- | ---------------------- | ---------------------- | ------------------- |
| 调节亮度 | `{"亮度百分比": <数>}` | 亮度百分比 0-100       | `{"亮度百分比":80}` |
| 调节色温 | `{"色温": "<值>"}`     | 暖黄光/冷白光/中性白光 | `{"色温":"暖黄光"}` |

**请求示例**（全部灯）：

```json
{ "zone": "meeting_room", "全部": true, "指令": "调节亮度", "参数": { "亮度百分比": 80 } }
```

**请求示例**（具体设备）：

```json
{ "zone": "meeting_room", "设备": [{ "设备名称": "light_001", "指令": "调节色温", "参数": { "色温": "暖黄光" } }], "全部": false }
```

## 3. 空调控制接口

**路径**：`POST /api/hvac/control`

### 请求体通用结构

```json
{
  "zone": "meeting_room",
  "设备": [{ "设备名称": "ac_001", "指令": "温度设置", "参数": { "数值": 24 } }],
  "全部": false
}
```

### 字段说明

| 字段   | 类型    | 必填                | 说明                              |
| ------ | ------- | ------------------- | --------------------------------- |
| `zone` | string  | 是                  | 区域标识                          |
| `设备` | array   | 当全部=false 时必填 | 设备操作列表                      |
| `全部` | boolean | 否                  | 若为 true，控制该区域所有空调设备 |

### 指令列表

| 指令         | 参数                    | 参数说明                 | 示例                   |
| ------------ | ----------------------- | ------------------------ | ---------------------- |
| 开关控制     | `{"打开/关闭": "<值>"}` | 打开/关闭                | `{"打开/关闭":"打开"}` |
| 运行模式控制 | `{"模式": "<值>"}`      | 制冷/制热/除湿/送风/自动 | `{"模式":"制冷"}`      |
| 温度设置     | `{"数值": <数>}`        | 温度值 16-30             | `{"数值":24}`          |
| 风力控制     | `{"风力": "<值>"}`      | 高/中/低/自动            | `{"风力":"自动"}`      |

## 4. 消息推送接口（反馈）

**路径**：`POST /api/send`（或 `POST http://127.0.0.1:18900/send`）

### 请求体

```json
{
  "jid": "niujunke@im.tuguan.net",
  "body": "已为您关闭大会议室灯光。",
  "from": "a01@im.tuguan.net"
}
```

**测试阶段**：所有推送统一发送至 `niujunke@im.tuguan.net`。
**生产环境**：根据设备类型（P01/P02/P03）发送至对应 JID。
